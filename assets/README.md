# /assets — documents iconographiques

Déposez ici les images documentaires. Le site ne télécharge rien et ne fabrique
aucune reproduction : si un fichier est absent, un emplacement « document
manquant » s'affiche à sa place, avec le nom de fichier attendu.

## Règles

- Les extensions `.png`, `.webp`, `.jpg` et `.jpeg` sont acceptées automatiquement
  pour chaque emplacement (le site essaie les variantes dans cet ordre).
- Ne jamais renommer une capture d'un autre jeu pour l'utiliser comme capture de
  *Crows* : la section « Influences et parentés vidéoludiques » l'annonce
  explicitement comme extérieure au jeu Saturn.
- Les légendes sont définies dans `app.js` (propriété `caption` de chaque image) et
  doivent rester factuelles.
